# Komet — веб-версия для iPhone

Задачи, пары и заметки в одном месте. Пишешь что угодно в одну строку — Komet сам понимает, задача это или заметка,
в какой раздел её положить и какой у неё срок («сдать лабу до пятницы !!», «свести бит завтра»).

- **Сегодня** — что горит прямо сейчас, пары и план по дням
- **Задачи** — по разделам; свои разделы под свои хобби (шаблоны: спорт, работа, дом…)
- **Пары** — расписание с числителем и знаменателем
- **Заметки** — заголовки, жирный/курсив, списки, чек-листы
- **Напоминания** — утренняя сводка, перед парой, о дедлайнах
- Работает без интернета, данные хранятся только на телефоне

## Как поставить на iPhone

1. Открой ссылку на Komet в **Safari**.
2. Нажми «Поделиться» → **«На экран „Домой“»**.
3. Открой Komet с экрана «Домой» → Ещё → Настройки → «Включить напоминания».

Нужна iOS 16.4 или новее.

## Перенос с Mac

В Mac-версии Komet: Настройки → iPhone → «Сохранить для веб-версии». Файл открой на телефоне:
Ещё → Настройки → «Загрузить».

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # разбор фраз сверяется с Mac-версией, шифрование push — с RFC 8291
npm run build
```

## Сервер напоминаний (Cloudflare Workers, бесплатно)

Веб-приложение не может само запланировать уведомление на завтра, поэтому напоминания присылает маленький сервер.
Телефон отправляет ему расписание на неделю вперёд (время, заголовок, текст), сервер раз в минуту рассылает то, чьё время пришло.

```bash
cd worker
npx wrangler login                                   # вход в Cloudflare
npx wrangler d1 create komet-push                     # id базы → в wrangler.toml
npx wrangler d1 execute komet-push --remote --file schema.sql
node ../scripts/vapid-keys.mjs                        # VAPID_PUBLIC → в wrangler.toml
npx wrangler secret put VAPID_PRIVATE                 # VAPID_PRIVATE из того же вывода
npx wrangler deploy                                   # адрес вида https://komet-push.<имя>.workers.dev
```

Адрес сервера укажи в репозитории: Settings → Secrets and variables → Actions → Variables → `PUSH_URL`.
